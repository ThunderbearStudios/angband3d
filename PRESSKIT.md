## 📜 Description

### 50-Word Elevator Pitch
**Angband 3D** brings the foundational 35-year-old classic roguelike *Angband* into immersive first-person 3D. Rather than creating a shallow action clone, it runs the authentic, unmodified Angband 4.2.6 C engine behind a continuous 3D world—preserving bit-for-bit mathematical rules, 0-turn camera yaw, dual-reality CRT terminal switching, and universal save compatibility.

### Full Summary
Classic roguelikes like *Moria* (1983) and *Angband* (1990) represent over three decades of continuous balance, complex item generation algorithms, tactical monster AI, and emergent dungeon ecology. Most modern attempts to bring classic roguelikes into 3D make a fatal mistake: they rewrite the game from scratch, discarding decades of battle-tested depth in favor of generic action-RPG mechanics.

**Angband 3D takes the opposite approach: Preservation Over Reimplementation.**
The authoritative, unmodified Angband 4.2.6 C engine runs as the backend server. Every monster stat, spell saving throw, level feeling, and procedural vault runs bit-for-bit upstream C algorithms. Presentation is completely decoupled via a high-speed, zero-allocation C JSON bridge.

Players explore dark, atmospheric stone dungeons with first-person spatial presence, dynamic torchlight, and normal-mapped textures. Yet every move remains turn-based: looking around costs precisely zero turns, while stepping forward passes time. With a single tap of `[Tab]`, the game instantly cross-fades into an authentic 80×24 CRT ASCII terminal—uniting 1990 nostalgia with 2026 modern graphics.

## 🌟 Key Features

* **⚙ 100% Authentic Angband 4.2.6 C Engine**: Unmodified upstream C game mechanics. Every monster roll, stealth check, artifact generation, and pseudo-random seed is mathematically identical to classic Angband.
* **👀 0-Turn Camera Yaw**: Solves the classic turn-based dilemma in 3D. Pan 360°, inspect vaulted corridors, and scout enemy packs without passing a fraction of a turn. Time moves only when you take a step or cast an action.
* **⌨ Dual Reality [Tab] CRT Terminal Mode**: Instant, seamless toggle between modern first-person 3D and classic 80×24 green/amber CRT phosphor ASCII terminal. Both realities run concurrently with zero state desynchronization.
* **💾 Universal .SAV Portability (`SaveVNLA`)**: 100% binary save file interoperability. Dive into the dungeon on your lunch break in a browser, export your `.sav` file in one click, and continue on your Windows PC or Android phone completely offline.
* **📖 The Living Chronicle (AI-Voiced Adventure Tome)**: In-engine tactical events (slaying unique monsters, surviving dragon breath, quaffing unidentified potions) are penned in real time into an illustrated fantasy tome, dynamically narrated by Gemini Native Audio voice stems (Master Bard Enceladus & Lorekeeper Aoede).
* **🏹 Tactical Depth & Monster Ecology**: 624 lore-accurate monsters and items, featuring authentic infravision, light radii, sound propagation, phase door tactics, and unforgiving permadeath.
* **📱 True Cross-Platform Parity**: Runs at 60 FPS in desktop and mobile web browsers with responsive split-thumb virtual controls, alongside dedicated 144+ FPS standalone Windows Desktop and Android APK binaries.
* **🌍 100% Free, Open Source & Extensible**: Fully documented JSON wire protocol (`docs/PROTOCOL.md`) and generic engine integration blueprint (`docs/GENERIC_ENGINE_INTEGRATION.md`) inviting modders to bring *NetHack*, *Moria*, and *DCSS* into 3D.

## 🏛️ Technical Innovations

1. **Zero-Allocation C JSON Bridge**:
   Angband's standard terminal abstraction (`term`) is hijacked by `main-bridge.c`. Instead of rendering glyphs to a console, the engine emits compact, zero-allocation JSON frames over `stdio`. The front-end renders these into a 3D procedural world without modifying a single line of game balance code.
2. **WebAssembly Asyncify Web Worker Thread Isolation**:
   In web browsers, the C engine compiles to WebAssembly via Emscripten and runs inside a dedicated Web Worker using Asyncify. The main UI thread and Three.js WebGL renderer stay locked at 60 FPS without ever being interrupted by engine compute cycles.
3. **Dual Reality Architecture**:
   The engine's 80×24 ASCII screen buffer is rendered to an offscreen canvas and fed through a custom CRT scanline and phosphor bloom fragment shader. Pressing `[Tab]` instantly fades the 3D viewport into the CRT terminal, proving that 3D immersion and ASCII purity are complementary perspectives of the same simulation.
4. **Universal Binary Save Interoperability**:
   Character `.sav` files produced in the web browser (via Emscripten `IDBFS`) are byte-for-byte identical to savefiles generated on native 64-bit Windows PC and Android builds. Players can migrate their runs across platforms at any point in their descent.

## ♿ Accessibility & Inclusivity

* **Motion Sensitivity / Visual Processing**: Instant [Tab] toggle to 2D CRT mode eliminates 3D motion sickness for sensitive players.
* **No Twitch Reflexes**: 100% turn-based execution and 0-turn camera yaw allow players with motor impairments to plan moves at their own pace without physical time pressure.
* **Auditory Redundancy & Closed Captions**: All acoustic combat cues are mirrored in the visual top banner and expandable message drawer. Video showcases feature full closed captions (`[CC]`).
* **Acoustic Safety**: Master Web Audio DSP dynamics limiter with a hard -6 dB ceiling prevents sudden volume spikes.
* **Ergonomic Controls**: Full keyboard remapping, standard roguelike numpad/arrow support, and split-thumb mobile touch ergonomics.
